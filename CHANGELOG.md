# Changelog

All notable changes to TerraDesk are documented here.

## [0.1.0] – 2026-11-23

### Added
- Initial release of TerraDesk
- Isometric world renderer with procedurally drawn buildings
- 60×60 tile grid with river terrain generation
- 14 building types: house, farm, market, school, hospital, church, tavern, well, mill, blacksmith, warehouse, road, tree, bridge
- Full citizen AI system with needs (hunger, energy, social, happiness)
- A* pathfinding for citizen movement
- Day/night cycle with dynamic lighting overlays
- Four seasons: spring, summer, autumn, winter
- Dynamic weather: clear, cloudy, rain, heavy rain, snow, storm, fog
- Economy system: taxes, salaries, food production, resource trade
- God Mode panel with 12 supernatural controls
- Build mode with 6 category tabs and cost display
- Citizens panel with individual detail view
- Economy panel with tax controls and market trading
- Statistics panel
- Environment panel for direct weather/season/time control
- Settings panel with save/load and desktop mode toggles
- JSON autosave system (saves to ~/.terradesk/saves/)
- Camera pan (keyboard + middle-mouse drag) and zoom (scroll wheel)
- Notification system
- Tooltip system on hover
- Ghost preview for building placement
- Meteor God Mode event with particle effects
- Windows desktop integration (always-on-top)
- Starter village generation on new game
